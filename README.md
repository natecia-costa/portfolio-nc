# Portfólio | Natécia Costa

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades e projetos na área de desenvolvimento Front-end.

## 🚀 Tecnologias

* HTML5
* CSS3
* JavaScript
* React
* Vite
* Git e GitHub

## 💻 Sobre o projeto

O projeto foi desenvolvido em React com foco em uma interface moderna, responsiva e intuitiva, reunindo informações sobre mim, minhas habilidades e principais projetos.

## ✨ Funcionalidades

* Apresentação pessoal
* Seção sobre mim
* Exibição de projetos
* Tecnologias utilizadas em cada projeto
* Links para os projetos e respectivos repositórios
* Seção de habilidades
* Formas de contato
* Layout responsivo para diferentes tamanhos de tela

## 📚 Objetivo

Este projeto faz parte do meu processo de aprendizado e prática em desenvolvimento Front-end, colocando em prática conceitos de React, componentização, CSS, responsividade e organização de projetos.
